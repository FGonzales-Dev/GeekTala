Noote redesign — mobile & desktop dialogs

Proposal: replace the mobile bottom tabs and floating button with an Apple Notes-style flow — Folders → notes → note — hide Shared until sharing exists, drop the grey fill from text fields everywhere, and give the desktop's dialogs one designed look instead of stock Material ones.

What changes

No bottom tabsFolders is the home screen. Tap a folder to see its notes, tap a note to edit. Back goes up one level, like Apple Notes.
Shared is hiddenRemoved until sharing is built. The hard-coded "Work / Personal / Shared" chips go too — folders replace them.
No floating buttonNew note sits in a bottom bar with the note count (and New folder on the folders screen). Settings moves to a gear at the top.
No grey text fieldsSearch, the note title, sign-in and dialog fields get a plain background with a thin outline (none for the title).

Plan

  1. Text fields (whole app). Turn off the grey fill in the theme (inputDecorationTheme): plain background, thin outline, darker outline on focus. The note title and in-editor fields get no fill and no outline. Fixes desktop too.
  2. Folders home screen. New mobile home: All Notes, the folder tree reusing the desktop's show/hide subfolders, tags, Recently Deleted. Gear → Settings (a full screen, no longer a tab). Bottom bar: New folder, sync status, New note.
  3. Folder screen. Back to Folders, large folder title and count, search scoped to the folder, its subfolders, notes grouped by date. ••• menu: Import Markdown, Select notes. Bottom bar: count and New note (into this folder). "All Notes" uses the same screen across every folder.
  4. Remove the tabs, the floating button and Shared. Delete the bottom tab bar, the FAB and the hard-coded Work/Personal/Shared chips; hide "Shared" (and "Shared with me" on desktop) until sharing exists. Routes become / (folders), /folders/:id, /notes/:id, /settings; the system Back button walks back up.
  5. Note screen. Back goes to the folder you came from; remove the Share button; make the bar above the keyboard work (text styles, checklist, list, code, attach, Done) — today only attach does anything.
  6. Desktop layout stays as it is, apart from the text-field fix and hiding Shared.
  7. One dialog component. A shared NooteDialog (icon, title, summary, close; body; footer with keyboard hint and buttons) plus shared buttons (primary, secondary, red, quiet), option cards and fact chips. Esc/↵, first-field focus, a short fade-and-scale in. Phones show the same content as bottom sheets.
  8. Settings as a window with sections — Appearance (theme previews, reset pane widths), Editor (paste Markdown, PDF previews default), Sync & account (account card, sync status, automatic sync, upload/download), About. On mobile the same sections become the Settings screen.
  9. Rebuild every dialog on it: delete folder (counts, option cards), new folder / rename (with where it goes), move to (search, current folder marked), tags (search or create in one field), sign out and download (say what's not uploaded), import into an existing folder (counts worked out before asking), delete forever.
  10. Tests. Navigation (folders → notes → note and back, Android Back), new note lands in the open folder, no tab bar or FAB on mobile, no Shared anywhere; each dialog's keyboard behaviour and what it changes; then try it on your Mac and Galaxy.
Mockup only — colours, fonts and sizes match Noote's theme; real notes and folder names are illustrative.
