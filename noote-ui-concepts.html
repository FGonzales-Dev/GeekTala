Local-First Sync Architecture
H
Overview

Every write hits the local SQLite database first — the UI never waits on a network call. PowerSync then pushes changes to Postgres once the device is back online, and pulls down changes made elsewhere.

  • Drift for local storage (SQLite)
  • PowerSync for offline-first sync
  • Supabase for backend, auth, and storage
